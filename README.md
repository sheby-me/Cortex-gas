# 🎓 Cortex – AI-Powered Peer Learning Ecosystem

## Overview

**Cortex** is an AI-powered peer learning platform designed to transform the way students collaborate, learn, and teach. Instead of relying solely on traditional tutoring or online resources, Cortex creates a collaborative ecosystem where knowledge becomes a valuable currency.

Students can teach subjects they excel in, earn credits for helping others, and spend those credits to receive guidance from peers or verified teachers. By integrating Artificial Intelligence, Cortex provides personalised learning experiences, helping students understand concepts, generate study materials, prepare for exams, and improve their academic performance.

The platform combines the collaborative aspects of peer learning with the intelligence of modern AI, creating an engaging environment where learning is interactive, rewarding, and accessible.

## 🎯 AI-Powered Study Assistant

Powered by **Google Gemini API**, Cortex provides an intelligent study assistant capable of:

* Generating lecture notes
* Summarising uploaded study material
* Creating personalised quizzes
* Producing flashcards
* Generating practice questions
* Creating revision notes
* Building structured study roadmaps
* Explaining difficult concepts in simple language

The AI focuses on helping students understand concepts rather than simply providing answers.

## 🤝 Peer Learning Marketplace

Students can create detailed learning profiles by specifying:

* Topics they need help with
* Learning goals
* Languages spoken
* University information
* Academic interests

The platform enables students to exchange knowledge through a collaborative learning network.

---

## 💰 Credit-Based Learning Economy

Cortex introduces a unique knowledge economy.

Every student begins with a set number of learning credits.

Students earn credits by:

* Teaching other students
* Answering community questions
* Helping with urgent requests
* Contributing educational resources
* Maintaining learning streaks

Credits can be used to:

* Book tutoring sessions
* Access premium AI features
* Request personalised learning support
* Connect with verified teachers

This reward system encourages continuous collaboration while promoting active learning.

---

## 🆘 SOS Learning

One of Cortex's flagship features is the **SOS Learning System**.

Students can instantly request help when facing urgent academic challenges, such as:

* Exams the following day
* Upcoming quizzes
* Assignment deadlines
* Difficult concepts requiring immediate explanation

Each request includes:

* Subject
* Topic
* Description
* Urgency level
* Preferred language
* Credits offered
* Expected session duration

Other students can respond, offer assistance, and begin collaborative learning sessions.
